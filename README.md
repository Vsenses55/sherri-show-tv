## Getting started

```bash
npm install
npm run dev
```

This starts a local dev server (Vite) with hot reload.

To build a production bundle:

```bash
npm run build
```

The output goes to `dist/`.

## Structure

- `src/app/` — the actual application: `App.tsx` and `routes.tsx` wire up routing, `MyPage.tsx` is the site itself, and `components/` holds the real page components (navigation, event calendar, listings, video player, footer, form fields, and the shadcn/ui component kit).
- `src/imports/` — raw component code generated directly from the Figma layers by Figma Make. Treat this as source material rather than something to build new features in directly.
- `src/assets/` — images exported from Figma.
- `src/styles/` — global styles, Tailwind config, and the design system's theme file.

## Deployment

Pushing to `main` triggers a GitHub Actions workflow (`.github/workflows/deploy.yml`) that builds the app and publishes it to GitHub Pages automatically. No manual deploy steps needed.
